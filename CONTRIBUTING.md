# Contribution scope

This is an unpublished candidate. No public issue tracker, pull-request endpoint or community is configured. Do not infer an invitation to upload private materials. Contact/reporting routes must be decided before publication.

Changes should stay within English-to-Chinese technical translation rules, explicit mechanical contracts, evidence binding and honest QA handoff. Prefer a narrowly scoped defect description: candidate version, OS/architecture, Python and locked-package versions, command with paths anonymized, expected versus actual status/error code, and a minimal original synthetic reproduction. Do not send whole institutional PDFs, restricted translations, personal paths, credentials or private logs.

Use the [Windows quickstart](docs/quickstart.md) and existing tests. Preserve fail-closed input checks, no-overwrite behavior and the distinction between synthetic records and real QA. A contract change needs an explicit version/compatibility decision and both positive and negative cases. Do not silently drop a check to make a fixture pass. Record skipped/unavailable tests as such; never infer results on another platform.

Use material you are authorized to contribute and state its origin, AI assistance and any upstream attribution/terms. Dependency usage is not evidence that dependency source was copied. The project uses the standard [MIT License](LICENSE). Contributors must have rights to provide their content and identify third-party sources and terms. This document introduces no signed CLA process and does not transfer future contributors' copyright to Hug800mhz. No existing contributors are implied. For sensitive issues, follow [SECURITY.md](SECURITY.md).
