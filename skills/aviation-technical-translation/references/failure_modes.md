# Failure modes and preventive controls

Consult the matching failure when it occurs or its risk is present. The preventive controls are invariants in that workflow, not an instruction to execute every row for every task. Project-specific evidence belongs in case lessons.

Workflow 1.2 supersedes historical blanket rerender/dispatch wording below: see dual_agent_workflow.md, evidence_contract.md and word_execution.md. Read the two-project retrospective for evidence and counterexamples. A failure is artifact-scoped; an old failed version is neither a current blocker nor cached PASS. Two unchanged failure cycles require root-cause/checker diagnosis.

| Failure | Why it failed | Prevention and detection |
|---|---|---|
| Global `Validation -> 确认` | It erased V&V and ordinary-confirmation distinctions. | Phrase-first context classification; block-level review; forbid unconditional single-word replacement. |
| Global `test data -> 试验数据` | ML evaluation data and engineering test data are not always the same. | Classify data provenance and use; check nearby ML/test context. |
| Global `Solution -> 求解` | Proposed solutions, configured systems, and mathematical solutions were conflated. | Classify the referenced object; use an approved phrase mapping. |
| `Issue` treated as one Chinese word | Edition labels became “problems,” or problems became editions. | Protect document issue/revision fields and inspect noun/verb context. |
| Safety and Security collapsed | Accidental-harm risk and malicious/unauthorized threats lost their distinction. | Separate context classes and run a dedicated terminology audit. |
| Machine-translated PDF used as source authority | OCR/text layers, numbers, and page objects were unreliable. | Source manifest and provenance; English source remains authoritative. |
| Normative force added or weakened | Descriptive language became a requirement or a shall became optional. | Modal-force comparison and reviewer evidence. |
| Suspected source error silently corrected | The translation no longer represented the source. | Record SOURCE_QUIRK; require human adjudication. |
| Chinese figure label covered an arrow or axis | Text was placed without checking geometry at full scale. | Compare with source, keep object-clear zones, inspect at 200%. |
| Repeatedly patching a low-quality raster | Each paint-over worsened anti-aliasing and legibility. | Re-export or rebuild from a source-quality asset; do not keep patching degraded pixels. |
| Word compressed images | Delivered figures became visibly soft. | Disable compression, record source hashes/dimensions, verify PDF at original scale. |
| NoTOC heading entered the TOC | Visual style and outline level were not separated. | Explicit whitelist; NoTOC style without `w:outlineLvl`; compare refreshed TOC results. |
| `python-docx` TOC assumed updated | A field code existed, but Word had not refreshed its result. | Use the project's verified Word invocation; inspect saved DOCX caches against PDF TOC and actual heading pages. |
| Unicode text simulated an equation | It lacked true OMML structure and wrapped/rendered unpredictably. | Generate OMML and inspect Word `OMath` objects. |
| Superscript text simulated a footnote | It lacked a Word footnote relationship and numbering behavior. | Insert true Word footnotes and validate anchors/counts. |
| Adjacent unrelated tables merged after Word save | Word joined a requirement frame and following table. | Preserve their independent owners using a controlled separator and rendered check. Legitimate continuation tables may merge with source-cell/header-alias mapping; output physical table count need not equal source count. |
| Bibliography wrapped under the label | Spaces were used instead of a hanging indent/tab stop. | Measure separate marker, tab, body and continuation anchors; inspect actual PDF, contextualSpacing and split-paragraph behavior. See PDF/Word routes. |
| Caption duplicated | The figure asset already contained a caption and Word added another. | Record `caption_embedded`; enforce one caption source. |
| Table header appeared multiple times in extracted PDF | Repeating Word headers were counted as source duplicates. | Distinguish DOCX semantic rows from rendered page occurrences. |
| Only the marked comment was fixed | Same-class defects elsewhere remained. | After the relevant correction batch, run a document-wide defect-class scan; repeat only after a relevant change or failure. |
| Content block vanished during a merge | The builder deleted a continuation block and broke traceability. | Ledger each source block; use `merged` and `merged_into`. |
| Visual contact sheet treated as complete review | Small defects were invisible. | Readable actual pages plus enlarged dense objects; bind checked aspects and criteria. Pixel equality cannot repair a revoked or inadequate old review (workflow.py cache). |
| Word save looked like a content change | Run splits, bookmarks, IDs, and rsid values drifted. | Compare raw text before canonicalization, reject in-word U+FEFF and misplaced run properties with docx_preflight.py; then compare semantic objects and a narrow package allowlist. |
| Final scrub audit used an older Word save as its package baseline | A later Word reopen changed non-semantic font hints, rsid lists, or shape-ID allocation, so the audit mixed serialization drift with the scrub delta. | Use the immediate Word-reopened pre-scrub work copy as the final package baseline; keep earlier renders for content and visual history. |
| Metadata leaked internal pipeline information | Core/custom properties retained author, paths, timestamps, or build strings. | Scrub after final Word update, inspect all properties, and run package regression. |
| Metadata scrub passed with comments or custom properties left behind | Removal was optional or verification trusted caller-supplied keywords, leaving review text and internal properties in the delivery. | Remove custom properties and complete Word comment artifacts by default; fail closed on residual parts, relationships, content-type entries, anchors, or references. |
| Empty typed metadata date corrupted the DOCX | `dcterms:created/modified` retained W3CDTF typing but contained an empty value that Word rejected. | Remove typed date nodes or write valid W3CDTF; reopen in Word before acceptance. |
| Version label reused for different artifacts | Baselines with the same label had different structures. | Identify artifacts by path + SHA-256 + build ID + object counts. |
| Missing OMML/footnote marker silently skipped | A superficially valid DOCX contained unfinished objects. | Missing or duplicate action marker is fatal; leaked marker count must be zero. |
| Low-cost model guessed a RED term | An unsupported regulatory/airworthiness choice became silently authoritative. | Apply highest-risk-wins classification; suppress low-tier RED proposals; keep a structured OPEN escalation item until required review closes it. |
| Finding self-declared a higher assessor tier | Untrusted provenance replaced the current run's actual authority, so an AMBER item could close without the required reviewer. | Treat CLI/run context as the trusted ceiling; route with the lower of origin and CLI tiers and record rejected elevation. |
| Ordinary QA confused with advanced review | The normal independent checker was forbidden by the legacy escalation switch. | Exactly one ordinary QA is part of document work; manual_handoff gates real technical decisions and extra capability, never silently upgrades a model or adds a third reviewer. |
| Cost profile weakened acceptance | Economy routing was treated as permission to skip evidence or QA. | Cost selects execution/review tier only; source authority, schemas, human gates, and publication acceptance remain unchanged. |
| Requirement frame attached by visual proximity | Repagination left the frame under the wrong heading even though it looked nearby before the edit. | Store unique `owner_ref` and `source_owner_ref`; validate same-section preceding-heading ownership and source order before/after Word pagination. |
| Figure and table captions drifted into different direct formatting | Visually similar captions had inconsistent fonts, sizes, or spacing and later edits amplified the difference. | Use semantic caption roles controlled by the selected profile; run same-type style consistency and rendered placement checks. |
| TOC text passed but spacing did not | Entry text/page numbers were correct while last-entry, group, or special-entry gaps diverged from source. | Capture source-relative spacing evidence and compare refreshed Word TOC visually, including terminal and group relationships. |
| Publication evidence downgraded its own required checks | A result file marked source-required TOC checks not applicable or claimed a section override was applied when it was not. | Bind required checks to the approved layout specification; require override application and matching section role before PASS. |
| One spacing rule applied to every Annex/special section | A document's distinct Annex, Bibliography, or Back Cover treatments were flattened. | Permit source-evidenced per-section spacing overrides; never promote one repair value to Core. |
| Brand mark clipped or cropped | Fixed line height, drawing bounds, or page position hid part of a flag/logo while its file was complete. | Lock aspect ratio; check crop and page/drawing bounds; review the Word-exported PDF/page raster at object scale. |
| Font axes were set as one value | Latin and Chinese text fell back unpredictably, changing wrapping and pagination. | Set `eastAsia` separately from `ascii`/`hAnsi`, keep math in Cambria Math, and rerun Word pagination plus all-page QA after any font change. |
| Local repair drift hidden by allowlist | A localized repair changed an unexpected page. | Compare actual render deltas; unchanged pages need valid exact reuse evidence, unexpected changes need impact review or authorization, not a retroactive allowlist. Source-permitted reflow is reviewed at actual pagination, not forced to old counts. |
| Single Word render treated as deterministic | A transient Word field, font, or pagination difference was never exposed. | Independently render the same final DOCX twice and block on any structure, dimension, or decoded-pixel mismatch. |
| Raw PNG file hashes compared instead of decoded pixels | Metadata or encoder differences caused false instability, or equivalent pixels were not distinguished from file bytes. | Compare decoded dimensions and pixels; retain encoder/file hashes only as secondary evidence. |

Treat corrective scripts from one project as evidence, not reusable policy. Extract the invariant and parameterize it; do not copy hard-coded block IDs, page numbers, counts, paths, hashes, or replacements into the core Skill.
