# 接收 续接与局部修订

## 新任务只明确一次

核对本次英文权威源、目标格式、文档类型、术语来源、图件权限、适用样式及交付范围。已有有效指定和授权直接复用；仅缺少会改变产物的选择才集中询问。`translation_only` 与 `publication_grade_docx` 是既有兼容字段；前者也可能要求严格 PDF 版式，不能据此降级。

PDF 默认按本篇源文结构制作中文稿；中英交替页、对照附页或完全改版须有对应要求。论文走 [pdf_workflow.md](pdf_workflow.md)，可编辑 Word 走 [publication_workflow.md](publication_workflow.md)。文件类型不决定审校深度，机构手册也不代表固定字号。

早期检查实际所需的字体、原生公式、图件文字提取、渲染与 Word 能力。样稿涵盖本篇有风险的标题、列表、表格、细线、图标记、脚注、行内公式及跨栏/跨页续文；源图数量和页数只用于本篇。样稿应比较源文角色及实际成品，先修共同根因再全篇装配。

已有 `inventory_project.py` 和 `validate_project.py` 可生成独立 intake 报告；不要重复建立另一份清单。缺中文初译不阻断；缺预批准术语/图片时先看用户是否授权建立候选。QA 验证的候选可以进入人工终校，但不写成 HUMAN_APPROVED。缺权威源只阻断依赖它的翻译，缺渲染阻断相应视觉验收。

结构化内容保留有序源 ID、表格坐标、图/公式/脚注/目录独立对象、恰好一次消费和合并谱系。应用 [translation_policy.md](translation_policy.md)；歧义按 [terminology_disambiguation.md](terminology_disambiguation.md) 分流，`term_guard.py` 只列上下文，不能按命中自动改词。代码、标识符、BibTeX 与算法叙述先分角色；源要求原样保留的对象可用 `check_invariants.py` 的 `preserve_exact` 校验。

成本和额外升级默认 `balanced/manual_handoff`；普通独立 QA 按 [dual_agent_workflow.md](dual_agent_workflow.md) 执行。旧分级适配器只用于实际需要的风险裁决，不是停工或升级模型开关。

## 局部修订

读取当前有效文件及本次批注，以章节、对象和文字锚点定位；旧页码只是定位线索。把同根因同范围修复成批处理。用户已批准的字体、颜色处理、技术决定继续在其范围内有效；新要求只覆盖冲突的范围，记录被替代决定，不把整份旧批准作废。

在既有问题记录中写明原值、预期值、源证、根因及影响对象，不再建重复台账。改动使用前置条件，禁止裸全局替换；公式、代码、链接及不同语境术语保留例外。

按 `workflow.py scope` 选择对象与变化页。未改变的语义可以复用，发现同类样式漏检则撤回相关检查结论；不把整篇“没有溢出”当作颜色/缩进/细线已核验。`workflow.py cache`要求声明实际检查内容，见 [evidence_contract.md](evidence_contract.md)。

## 恢复任务

复用已有 checkpoint 或当前状态文件，**只保留一个权威入口**：当前文件和 SHA、适用决定/规则、尚未完成的检查、实际模型/工具限制及下一动作。项目索引指向它；不再新增多层互相转引的状态报告。

先核对该入口及命名的当前文件。入口与工件不一致时查其交付清单和紧邻修复记录，登记差异，不按版本号最大者猜选，也不递归重哈希历史工程。活动 checkpoint 不加入冻结 QA 快照；冻结决定/内容需独立不可变副本。

工具版本、参数及成功运行配置一起恢复。遇到阶段超时，先比对同篇已验证的适用参数；不自动回退默认值或盲目连续重导。Word 进程按既有隔离协议处理，用户其他文档不受影响。模型切换本身不使已绑定且仍适用的内容证据失效。

保持已完成成果并继续授权范围内工作，直到交付或确有阻断；普通待办不是需要用户再次批准的事项。
