# Reuse verified Word execution, preserve permissions

Discover the current project runtime README, profile, exact source/run hashes and successful run evidence. Pin runtime/profile/environment versions. The installed headless v2 entry is the current approved tool routing for this user after its recorded tool acceptance. Preserve a project's explicit content/export mode; do not silently reuse legacy click-dependent wrappers. Approval is per actual permitted operation; no sandbox bypass, permanent security changes or mistaken historical authorization.

Executor is the only Word owner. Copy two final runs directly from the same frozen source; never derive run2 from run1 or copy a PDF as a second sample. For an update/save profile: inspect CURRENT fields and external targets; update confirmed internal story fields, cross-references, captions, PAGE/NUMPAGES and the whole TOC, repaginate, SAVE that run, close/release, reopen saved run, export, close/release. Verify TOC caches in the saved package against PDF AND actual body pages. Hash/mtime change alone does not prove cache correctness. Local `HYPERLINK \\l` with a resolvable bookmark is not an external file. Unknown/external dependencies need explicit access/decision.

Normal export is script-only. Use the installed `scripts/Export-Word.ps1` entry with explicit absolute InputPath, a new OutputDirectory, and UpdateSave or ReadOnly mode; see [word_export_tool.md](word_export_tool.md). Never use Computer Use, UIA clicks, SendKeys, keyboard/mouse input, clipboard, foreground focus, or a click-No fallback for successful export. The runtime audits field/dependency objects before opening, retains every dirty/lock flag and editable field, and temporarily scopes DisplayAlerts only to its own Documents.Open call with restoration/readback. Unknown dependencies or unexpected dialogs fail closed with evidence. Do not infer a real external dependency from Word's generic field advisory. Ordinary navigation hyperlinks are retained.

Log creation/open/update/TOC/pagination/save/reopen/export/close/Quit/release/natural-exit individually. Separate COM/export timeout from downstream PDF validation timeout. PDF creation is not proof that the entire workflow succeeded; a validator timeout is not a COM export failure. Use reasonable stage-specific bounds and preserve raw failure reports. Two no-progress attempts require root-cause diagnosis.

Use Document.Windows.Item(1).Hwnd for precise ownership when supported; record PID/start time/session. Never kill existing or unbound Word sessions. Normal exit = Quit + release + disappearance without forced cleanup, timeout or residual. A supported wrapper may safely require ownership for its process handling; never invent a new global rendering gate solely because optional telemetry is absent. If ownership is unavailable, no unsafe cleanup is allowed. Never use process-name bulk kills.

Final metadata-only validation: after preplanned scrub, export the exact final copy without update/save; content/layout parts unchanged. Use Word as authority, not LibreOffice fallback. GUI is an explicitly recorded invocation alternative when authorized and available, not an immutable rule overriding a later repaired automation route. PDF binary hashes may differ; compare decoded pages/content/geometry. Preserve exact scoped human microposition dispositions, never infer a universal tolerance.
