# 可复用的个人中文审校偏好

推荐提示词显式指定的宋体正文、黑体标题、Times New Roman 西文及本次字号行距优先，详细参数和疏页处理见 [排版与非交互验收](typography_and_headless_qa.md)。未采用该提示词且未指定字体时，中立默认仍为 `source_faithful`。用户明确采用某 profile 或要求沿用已认可样式时，在相同范围内继续，不再逐项询问；新的用户决定优先，冲突只在受影响范围替换。

- `personal_zh_review`：原有手册审校选项，正文/列表/书目宋体12pt，英文 Times New Roman，主要标题黑体，较低标题宋体；图题和脚注9pt，表题另定或10.5pt。仍需从本篇映射颜色、强调、几何与层级。
- `personal_paper_review`：论文偏好，中文正文宋体、各级标题黑体、英文 Times New Roman；字号依据本篇匹配度在用户已允许的四号14pt、五号10.5pt、小五9pt中选择并验证代表样页，标题和图表题联动。profile不固定9pt、14pt行距或原文页数。此前小四12pt要求已被论文任务中的后续授权放宽，不能再把12pt套到全部论文。

源文图像内部字体及数学字体单独按忠实性和许可处理，不承诺无条件全部替换为 Times New Roman。两端对齐需验证实际效果，不能拉散英文单词、公式或段末短句。

源文颜色和强调优先按对象保留。旧 `personal_zh_review` 的黑色定义标签可加粗仅是选中该旧profile时的偏好；**没有全局“删下划线”默认**。实际保留与替换范围由本次源文和用户决定。

页数、色值、机构名、章节ID、特殊页和表格比例留在项目数据。用户接受某篇现文，不会把该译法自动加入所有项目权威术语表。
