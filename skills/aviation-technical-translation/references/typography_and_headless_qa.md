# 可编辑排版参数与非交互验收

解析本次推荐提示词内的排版参数；用户附加的明确修改优先。将最终选用的字体、字号、正文相邻基线距（pt）写进同一份项目设置，生成器、小样、最终检查均读取该设置。推荐值为正文宋体（SimSun）、各级中文标题黑体（SimHei）、西文及数字 Times New Roman、正文 12 pt、主标题 16 pt、正文基线距 18 pt。次标题、图表和页注按层级设定。数学字形、符号、原样保留的标识、签字或图像文字单列。标题中的英文也使用所选西文字体的相应字重。混合段落按字符书写系统切换真实字体，核对子集与嵌入文件；单一 CJK 字体往往会吞掉英文。缺所选字体时定位合法的本机字体文件、已授权字体或用户明确批准的替代，记录实际字体名称。不要静默替代。

**页面较空时。** 先从真实译页区分段／图／表之间的空洞、普通正文下方可用空间与有用途的留白（扉页、章末、脚注、浮动图、双栏收尾）。先纠正旧纵坐标、空段和重复段距。有多张同类普通页明显偏空时，以小样在用户给定增量内一起试增正文字号及行距，作为一致的版式应用到同段落样式或同类页面；从其前后各一页检查。实测占用、字号和基线距，确认没有多余溢页、跨页断义、图题脱离或新空洞后才采用。用户给定精确值或关闭调节时照该值排。避免按每段的框高反算行距，也避免对单张稀疏页任意放大。

**实际 PDF。** 按项目实际 PostScript 字体名（含必要的常规／粗斜变体）列出允许的名称，用下面的输入格式描述真实正文和标题选区。在同一物理页同栏单段圈入完整文字及白边，不混入公式或另一样式。每种正文／标题样式及每类页面都应有选区，优先由构建器导出全部文字对象的版面位置，再独立对最终 PDF 和渲染检查。模板中的坐标、字体别名和大小仅作示例。

```json
{"roles":{"body":{"cjk":["SimSun"],"latin":["TimesNewRomanPSMT"],"size_pt":12,"leading_pt":18},"heading":{"cjk":["SimHei"],"latin":["TimesNewRomanPS-BoldMT"],"size_pt":16}},"regions":[{"id":"p1-h","page":1,"rect":[40,52,510,85],"role":"heading","scripts":["cjk","latin"]},{"id":"p1-a","page":1,"rect":[40,110,510,190],"role":"body","scripts":["cjk","latin"],"leading":true}]}
```

运行 `python scripts/pdf_typecheck.py final.pdf --spec roles-and-regions.json --output type-result.json`。工具检查所有命中的 CJK／西文字符，包括数字；缺字类、缺相邻行、其他字体或字号不符都不能取得 PASS。注释和数学等无法以字形层验证的范围在实页检查。用 `scripts/pdf_spacing.py` 实测段前与图表前后净空。

**默认及正式交付全程禁用 Computer Use。** 所有参与者使用本地文件、命令行与库；禁止派发到桌面或浏览器控制、UI 自动化、按键或系统剪贴板。用 PyMuPDF 和独立提取器（如 pypdf、Poppler pdftotext）从最终文件读回原始样本，核对中文、西文、数学、阅读顺序及隐藏重复层；用 Poppler 或 PDFium 渲染真实页图，读图复核文字、表格、矢量和链接落点。扫描页可用只读本地 OCR 辅助定位，仍须对照实际页。记录文件哈希、使用的提取器／渲染器、覆盖、差异与局限。在未操作阅读器的情况下，报告“文件文本层已核；阅读器剪贴板未测”，后者不阻断交付。
