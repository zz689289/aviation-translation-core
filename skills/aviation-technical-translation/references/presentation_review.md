# 呈现证据与交付阶段

用于自行排版、反馈修订或效果比较。现有源权威、差分复核和独立QA规则继续适用；不额外要求未交付的Word。

## 用可复核测量封闭首交盲点

- 表格内容、几何和强调是三类检查。源测量按表/单元格ID保留实际宽度、列边界、字体角色；输出测量独立来自交付PDF。数值一致不等于表宽或粗体还原。中文溢出先处理换行和行高，不无记录地把每表拉满栏宽。
- 列表群前后间距与标记、正文、续行三个锚点分别测量。项目中的“两字宽”等决定记录为相对量；不用字面空格模拟，也不推广某篇pt值为默认。
- 行内数学旁保留未经规范化的文本探针与正确阅读串。按逻辑段/数学资产核对语义文本层，不能把每行ActualText存在当成复制正确；重复字符、错字和图像数学缺失不得靠去换行掩盖。第二提取器结果用于定位分歧，不能冒充实际阅读器复制。本 Skill 禁用 Computer Use 和剪贴板。采用两个独立 PDF 提取器对照正文及数学读序，阅读器复制记为 NOT_TESTED，不作为阻断。
- 图中文字按描述语义、专用标识符、变量、单位和已批准保留项建立映射。保留模型ID不表示旁边坐标/模型描述也一律保留。先锁定曲线、箭头、边框、刻度及浅色边缘，再改字；每次从源质量资产生成。保护区、颜色空间和坐标变换随检查保存，不能失败后缩窄掩膜或放宽阈值消除差异。
- 两端对齐检查真实输出，特别是短非末行、数学邻接片段和英文整体。检查语义不被拉散，同时防止Δ与变量、括号或单位被单独换行；不通过删字符获得整齐外观。

### 在实际译页上复测行距与净空

行距取同栏、同样式、同一逻辑段落内主文字基线的相邻差，比较多个长短不同的段落。段前、图前、表前净空取上一对象可见墨迹底边至下一对象可见墨迹顶边；表题在上时从表题算起，图在前时从图的可见内容算起。对跨栏对象核对其上方每个被占用的栏。按语义对象重新定位重排后的译页。小样先确定本篇各类间隔的范围与必要例外；异常值结合可读原页和译页判断。标题层级、脚注预留、整组换页及图内留白分别核对用途。

可用 `python scripts/pdf_spacing.py 译稿.pdf --spec 选区.json --output 新结果.json` 记录选区和实测值。选区按未旋转页左上角 pt 填写，页码从 1 起。下面的坐标和验收范围仅演示输入格式，使用时换成本篇对象与小样范围。

```json
{"checks":[
  {"id":"body-a","kind":"leading","page":1,"rect":[40,120,260,170],"range_pt":[11.7,12.3]},
  {"id":"before-table","kind":"gap","page":1,"before":[40,145,260,178],"after":[40,179,260,210],"range_pt":[7,15]}
]}
```

`leading` 每框只圈同栏一个段落的主文字。`gap` 给出按阅读顺序相邻的两框，分别圈全前一对象末端、后一对象起始的可见内容，给相向边缘留少量白边，避开栏线和邻栏。图表外边界过浅、对象重叠、扫描正文或文字提取有偏差时，改用高分辨率裁图人工量测。`UNMEASURED` 要补查，样本通过仅覆盖所列对象。全页仍需检查未取样处和移位后留下的空洞。

可选机械入口：`tools/presentation_guard/scripts/check_presentation.py --root 私有运行目录 --spec presentation.json --output 新结果.json`。工具与公开核心候选逐字相同，比较显式范围内的度量/角色、原始UTF-8探针和解码P6 RGB裁片。独立源/目标profile、实际工件与证据均绑定哈希；具体格式见该工具docs/presentation_checks.md。需要明确的测量输入和jsonschema依赖；它不自动量测完整PDF，不证明测量人身份，也不取代语义/视觉/剪贴板QA。已有脚本不足以产生某项观测时，如实保留未测，不能填布尔PASS。

## 分开记录自主首交和反馈修订

一次任务对话中的翻译、排版、自检及自主内部修订共同构成首次对话交付流程；保存第一次完整生成稿和第一次正式交付的独立哈希。内部构建/修订次数不计为用户反馈。

用户反馈按轮次及原始问题条数记录；补充发现、同类扩展和修复执行者分开归因。没有直接人工编辑证据，不写成人工翻译或逐句编辑；没有计时，不估算人工耗时。用户决定分别作用于算法题目/内部语言、标点、字号或对象范围，不自动改写全局默认。

效果图固定使用英文原文、真实旧机翻、Skill首次对话交付、人工反馈后修订版。修订重排后重定位同一语义范围，明确无变化、偏好变化、代价和残留；第四栏不能替换第三栏，也不能证明候选Skill已在新论文自主达到第四栏水平。未知旧机翻设置写UNKNOWN，配置差异和公开范围待决单列。

## 本轮验证的生成层修复

不要用覆盖多个文字对象与图片数学的整行ActualText作为正常正文的替代。正文保持原生文字；经批准的数学图片逻辑串按单个资产使用scripts/pdf_text_layer.py的draw_logical_image_text钩子，保存/恢复图形状态。只删ActualText会丢变量，必须保留此失败对照并同时检查正文及数学符号；逻辑层不等于可编辑二维公式，也不替代原生复制测试。

图资产源渲染使用scripts/source_raster.py显式记录源图像色彩空间、渲染器、缩放和采样；后续嵌入相同不证明源颜色正确。源质量资产重放已批准标签后，检查预先声明保护区、穿越标签区的几何及最终PDF同条件颜色，不硬编码某篇RGB。

跨案例经验支持现有工作流减少用户逐条指导和纠错；不把整体收益全部归因于本轮增量，未测百分比不填写。
